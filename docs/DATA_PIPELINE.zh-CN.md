# 从原始信号到一条预测

[English](DATA_PIPELINE.en.md) · [README](../README.zh-CN.md) · [特征字典](FEATURES.zh-CN.md)

## 1. 数据到标签

固定处理链：读取物理单位的 EEG／ECG 和专家标签→统一 30 秒窗口→映射五类标签→EEG 滤波和频谱→ECG 心跳与 HRV→按人划分→训练集拟合预处理→组装历史上下文→模型输出五类概率。

![从原始信号到预测](figures/data_pipeline.zh-CN.png)

MIT-BIH 16 人、18 记录，保留 10,181 窗口；ISRUC III 10 人、10 记录，8,889 原始标签统一省略每记录末尾 30 个，共保留 8,589 窗口。按人划分为训练 15,761 窗口、测试 3,009 窗口，不设验证集。原始文件、窗口索引和排除规则分别由下载清单、`epoch_manifest.csv`、冻结协议记录。

ISRUC 用 EEG C4-A1、心电 X2（EDF transducer 为 EKG_Channel）、专家 1。MIT 读取记录中的首个 EEG 通道，导联随记录变化。MIT 旧 3／4 期合并 N3，ISRUC 0／1／2／3／5 映射为 Wake／N1／N2／N3／REM。未知标签不作为一种预测类别，直接排除并打断上下文。

## 2. EEG：原始波形到频谱

| 步骤 | 精确设置 |
|---|---|
| 单位 | 读取物理量并转为 µV |
| 基本检查 | 有限值；标准差至少 0.01 µV；绝对振幅不超过 2,000 µV |
| 滤波 | 每个 30 秒窗口独立做 4 阶 Butterworth 0.3–35 Hz、`sosfiltfilt` |
| 重采样 | `resample_poly` 至 100 Hz，每窗口 3,000 点 |
| STFT | 窗长 200 点（2 秒）、重叠 100 点（1 秒）、FFT 256 点；`boundary=None`、`padded=False` |
| 保留频率 | 0.3–35 Hz，共 89 个频率 bin；FFT 频率间距 100／256＝0.390625 Hz |
| 变换 | `log10(max(abs(Z)², 1e-8))`；29 帧×89 bins |
| 训练集标准化 | 按频率计算训练窗口及帧的均值／标准差；缩放后裁剪至 [−8,8] |

频谱是 STFT 对数平方幅值，未定义为标准物理单位 µV²/Hz 的功率谱密度。基本振幅规则没有移除本轮已标注窗口，也不能代替完整伪迹检测。逐窗独立处理不读当前窗口后的 EEG，但零相位滤波会使用该窗口内部较晚的采样点。

![实际 EEG、频谱、ECG 与 RR](figures/signal_walkthrough.zh-CN.png)

图中的 EEG／频谱来自同一个固定训练窗口，ECG／RR 来自另一个保存的训练片段，分别标注记录和时间，不冒充同一个同步片段。10 秒 ECG 的 RR 仅用于解释心跳间隔，实际模型 HRV 取最多 300 秒历史。波形的显示缩放不参与训练。

## 3. ECG→RR→HRV 的时间边界

SleepECG 0.5.9 在完整离线 ECG 上检测心跳。设心跳时刻为 `b₀,b₁,…`，RR 为 `bᵢ−bᵢ₋₁`，时间戳取其**末端 bᵢ**；不在 [0.3,2.0] 秒的 RR 标为 NaN，保留序列位置，不直接删掉。

目标窗口起点为 `t`、终点 `T=t+30`。特征提取参数为 lookback 270 秒、lookforward 30 秒，因此该窗口采用 RR 终点范围 **[T−300,T)**。不使用 T 之后的 RR 终点。首个纳入的 RR 可以跨越统计窗口左边界，因为以终点分组。完整离线检测器本身的滤波／检测过程尚未验证为严格实时因果实现。

26 个库特征的原始非有限值→训练集中位数填补→训练集均值／标准差缩放（最小标准差 1e−6）→裁剪 [−8,8]。26 个缺失标记在填补前生成。再加入 3 个覆盖量得到 55 维输入，详见[特征字典](FEATURES.zh-CN.md)。

时间边界描述的是选入窗口的 RR 数值。库的 pNN 分母还依赖同一整记录的最大填充宽度，较晚统计窗口可能影响该分母；因此不能由局部终点范围推断整个特征构建严格实时因果。

## 4. 历史上下文、填充与实际历史长度

![时间对齐与统计历史](figures/time_alignment.zh-CN.png)

- `L=5`：EEG 为当前及过去共 2.5 分钟；各窗口的 5 分钟 HRV 区间联合覆盖 `300+(5−1)×30=420` 秒，即 7 分钟。
- `L=15`：EEG 共 7.5 分钟；RR 终点统计区间联合覆盖 `300+(15−1)×30=720` 秒，即 12 分钟。
- 以上为完整历史下的统计区间；开头的窗口实际历史较短，也不表示原始 ECG 检测器仅读取这些区间。
- 上下文只在同一记录、同一划分、连续已知标签窗口内构建；未知标签缺口后重新积累。起始不足 L 个窗口时左填充，索引为 −1，并在时序注意力中屏蔽这些键。
- `history_fraction=min(T,300)/300` 描述该记录按时间可用的历史，不是有效心跳覆盖率，也不会因未知睡眠标签缺口清零。

## 5. 缓存、拟合统计与输出

| 文件 | 字段／作用 |
|---|---|
| `cache/deep_learning/<record>.npz` | EEG `(n,3000)`、频谱 `(n,29,89)`、HRV `(n,26)`、标签、原始 epoch；另保留本轮未使用的 7 项 EEG 手工特征 |
| `epochs.csv`／`results/v2/epoch_manifest.csv` | record、subject、source、epoch、stage、record_row、split，明确每一行对应关系 |
| `cache/v2/quality.npy` | 18,770×3，严格对应窗口清单行序 |
| `cache/v2/contexts.npy` | 18,770×15 历史索引，5 窗口组使用末尾 5 列 |
| `results/v2/preprocessing.npz` | 仅训练集拟合的填补／缩放统计 |
| `results/v2/predictions.csv.gz` | 每窗口标签、预测、五类概率、当前门控、覆盖量；56 组×3,009 行 |

增强增加训练输入变化，不增加独立受试者。窗口虽多，相邻窗口和重叠 HRV 历史高度相关。模型输出是专家标签的预测，并非诊断失眠、睡眠呼吸暂停或直接测量睡眠质量。
