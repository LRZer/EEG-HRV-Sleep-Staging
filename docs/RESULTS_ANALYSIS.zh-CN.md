# 结果解读、错误分析与证据范围

[English](RESULTS_ANALYSIS.en.md) · [README](../README.zh-CN.md) · [完整数值报告](../results/v2/report.zh-CN.md) · [分解表与案例](tables/result_breakdown.md)

## 1. 先区分三种成绩

1. **单个种子**：一次从头训练的模型在固定测试集上的结果。
2. **均值±标准差**：三个单次成绩的平均与样本标准差，是本轮对照实验的主报告方式。
3. **概率平均集成**：先平均三个模型每个窗口的五类概率，再得到预测并计算指标；不是三个 Accuracy／F1 的平均。

单次均值最高为 A1：Accuracy 67.22%、Macro-F1 0.6171；A1 集成为 70.22%／0.6407。A6 单次均值为 63.96%／0.5834，集成为 65.10%／0.5862。一个模型变体的均值不能与另一个变体的集成直接比较为改进幅度。

## 2. 每组对照支持什么结论

| 比较 | 本轮观察 | 可支持的范围 |
|---|---|---|
| A1−A0 | Accuracy +0.17 个百分点，Macro-F1 +0.0181 | EEG 的 15 窗口上下文比 5 窗口取得较高均值；效应只针对本次划分 |
| A3–A6 对 A0 | 所有融合组的平均 Accuracy／Macro-F1 较低 | 当前输入、融合和训练组合没有带来整体收益 |
| A4 对 A0 | REM F1 0.3688 对 0.2521；N1 F1 0.4263 对 0.5740 | 个别阶段改善不代表整体提高 |
| A5−A4，HRV 全缺失 | Accuracy +6.85 个百分点、Macro-F1 +0.0739 | 这次缺失模态测试中，含模态丢弃的组均值更高 |
| A6−A5，正常输入 | Accuracy −0.48 个百分点、Macro-F1 −0.0033 | 延长融合上下文在本轮没有改善均值 |

A4−A3 同时改变多项融合结构，尚未独立测量质量乘法因子的贡献。A5／A6 的全缺失成绩高于正常输入，也是保存结果中的观察；这不能独立证明 HRV 噪声、过拟合、特征公式、数据源差异或门控设计中的哪项是原因。

## 3. 如何读阶段、数据库与受试者图

![阶段 F1 与样本支持量](../results/v2/figures/per_class_f1.png)

**阶段图**：对照每类 F1 和真实支持量，测试类数为 Wake 882、N1 583、N2 875、N3 361、REM 308。样本数量不同，加权训练也不会保证每类表现相同。

**混淆矩阵**：行是真实阶段，列是预测阶段；对角线为正确识别，离对角线单元格为具体错误去向。计数与行百分比一起读，不能只看大样本类别。固定 A1／A6 集成每类最大的错误去向由[分解表](tables/result_breakdown.md)列出，全部七组矩阵见[图表目录](FIGURES.md)。

**分数据库图**：两个库都出现在训练集，所以分库成绩测的是各库未见受试者，不能称为跨库外部验证。MIT 测试 N3 只有 7 个窗口；某个阶段的成绩容易受极少窗口影响。

**分人图**：4 位受试者的记录长度与阶段分布不同。窗口汇总成绩不是四个人成绩的简单平均；逐人 Macro-F1 固定按五类平均，无该阶段时该类 F1 为 0。分人／分库 A0、A1、A6 均值和窗口数见[自动生成表](tables/result_breakdown.md)，完整七组在数值报告中。

## 4. 固定正确／错误案例

![A1 与 A6 的固定预测案例](figures/prediction_cases.zh-CN.png)

四个类别分别为两者正确、仅 A1 正确、仅 A6 正确、两者错误。选择规则固定为：正常条件的 A1／A6 三模型集成，按记录名与原始 epoch 排序，每类取 `epoch≥14` 的首例。**不是按最高置信度挑选，也不将四例称为整体代表性证据。**

浅绿色背景标出专家阶段；两组柱形给出五类概率。标题展示原始记录、零基 epoch、专家标签和 A6 当前门控；原始概率、三个覆盖量及标签均在[案例 CSV](tables/prediction_cases.csv)。同一个案例中较大的门控或较高的概率，不能证明模型的错误／正确来自某个具体生理机制。softmax 概率也未作校准，不能解读为已验证的可靠性。

完整睡眠时间图覆盖全部 5 条测试记录，避免仅展示局部成功片段；专家标签是评估参考，不是重新审定的独立临床真值。

## 5. 为什么不能据此宣称 HRV 无效

当前结果只说明**这套特征、数据、模型和训练设置**没有取得整体融合收益。已知条件包括：测试只有 4 人、复用留出集、两库 EEG 导联／评分不同、HRV 统计历史重叠、库的 pNN 分母与 cvSD 数值稳定性问题、只使用 26 项 RR／心率／几何特征。每项都应在后续独立实验中检验，不能凭现有结果认定为已证实原因。

| 尚未完成的检验 | 能回答的问题 |
|---|---|
| 修订 HRV 分母／单位约定，使用新协议重建并重跑全部对照 | 特征实现条件是否影响结论 |
| 保持残差结构，仅开／关质量乘法约束 | 质量约束的独立贡献 |
| 固定特征和训练，改变 HRV 统计时长 | HRV 时间尺度是否合适 |
| 新受试者或新数据库的独立最终评估 | 是否能推广到未参与方案设计的人群／来源 |
| 实时 ECG 检测、未标注文件推理、概率校准 | 部署边界、检测延迟和概率可信度 |

以上为未执行工作，不计入已完成成果；本次文档更新没有进行新训练或改变冻结成绩。

## 6. 保存与验证

已保存 21 个最终检查点、840 行训练日志、56 组×3,009＝168,504 行预测、各类／人／库指标、全部混淆矩阵及权重校验。既有[验证记录](../results/v2/verification.json)核对全部指标、受试者隔离、权重与 A6 概率恢复；在记录的复现检查中恢复标签全部一致，最大概率差为 0。这验证保存产物的可恢复性，不增加泛化证据。
